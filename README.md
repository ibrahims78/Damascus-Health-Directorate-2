## 🏬 نموذج المستودعات والقواعد (تطبيق واحد بسلوك حسب النوع)

التطبيق **واحد**؛ سلوكه يتغيّر حسب نوع **مستودع هذا الجهاز** (مركزي/فرعي):

| القاعدة | السلوك | الرمز عند الرفض |
|---|---|---|
| التحويل | من **المركزي إلى الفرعي فقط** | `TRANSFER_NOT_ALLOWED` |
| المركزية | مستودع مركزي **واحد فقط** | `SINGLE_CENTRAL_ONLY` |
| سند الاستلام | الفرع لا ينشئ سند استلام من مورّد | `BRANCH_NO_SUPPLIER_RECEIPT` |
| الإدخال المباشر | الفرع يستلم فقط عبر التحويل من المركزي | `BRANCH_INBOUND_VIA_TRANSFER_ONLY` |
| فروق الاستلام | **سبب إلزامي** لكل فرق في كمية الاستلام | `VARIANCE_REASON_REQUIRED` |
| المرتجع | الفرع يُرجع عبر «مرتجع إلى المركزي» فقط | — |

**الإعداد:** من الكتالوج ← تبويب «المستودعات» أنشئ المستودعات (رمز/اسم/نوع) ثم «تعيين كمستودع هذا الجهاز». للنشر متعدد المواقع: تثبيت لكل موقع مربوط بمستودعه + مزامنة.

المزيد: [نموذج المستودعات](docs/phase5-warehouse-model-ar.md) · [التحويلات](docs/phase6-transfers-ar.md) · [المزامنة بين المواقع](docs/phase7-multisite-sync-ar.md) · [التقارير الموحّدة](docs/phase8-consolidated-reports-ar.md).

## 🚀 البدء السريع (ويندوز)

1. نزّل `Windows-Protected.zip` (أو Portable) من صفحة الإصدارات
2. فكّ الضغط وشغّل **`مستودعات مديرية صحة دمشق.exe`**
3. عند أول تشغيل: أنشئ حساب المدير (شاشة «إعداد حساب المدير»)
4. **Protected فقط:** ستظهر شاشة «نسخة محمية» بمعرّف الجهاز — أرسله لمسؤول النظام لإصدار ترخيص 5.0.6، ثم الصقه في **«تفعيل التطبيق»**

> **مهم عند الترقية:** إن وُجد مجلد بيانات قديم في `%APPDATA%\Damascus Health Directorate\data` بمخطط أقدم، احذفه قبل أول تشغيل (نسخة نظيفة تعمل؛ لا توجد هجرة تلقائية للمخطط حالياً).

### أندرويد

ثبّت `Android-Offline.apk` مباشرة، أو `Android-Protected.apk` (اسمح بـ«مصادر غير معروفة») ثم أرسل معرّف الهاتف لإصدار ترخيص 5.0.6.

### الوصول من المتصفح (LAN)

| الخدمة | المنفذ | مثال |
|---|---|---|
| الواجهة | **41790** (ثابت) | `http://192.168.1.55:41790` |
| API | **41789** (ثابت) | `http://192.168.1.55:41789/api/healthz` |

```bat
netsh advfirewall firewall add rule name="DME Web 41790" dir=in action=allow protocol=TCP localport=41790
netsh advfirewall firewall add rule name="DME API 41789" dir=in action=allow protocol=TCP localport=41789
```

## 🔄 المزامنة بين الأجهزة

| السيناريو | الطريقة |
|---|---|
| ويندوز ↔ ويندوز | «المزامنة» → «مزامنة شبكية مباشرة» بعنوان الطرف الآخر `:41789` + بيانات مشرفه، أو ملفات `.dme-sync` |
| أندرويد ↔ أندرويد | تصدير حزمة → مشاركة الملف → استيراد وتطبيق (ثم العكس) |
| أندرويد ↔ ويندوز | الهاتف يبدأ «مزامنة شبكية مباشرة» بعنوان الويندوز `:41789` — أو ملفات |

الاستيراد مضمون ضد التكرار، والتعارضات تظهر في «طابور التعارضات» مع تسجيل تدقيق. المراجع: [دليل العمليات](docs/operations.md) · [ضمانات المزامنة](docs/sync-guarantees-ar.md).

## 🔐 الأمان

- **ترخيص Ed25519** بمفاتيح منفصلة لكل منصة — المفتاح الخاص خارج المستودع (`release-secrets/`، غير مرفوع).
- **حزم النسخ والمزامنة مشفرة** بكلمة مرور (AES-256-GCM + scrypt).
- كلمة مرور المدير تُنشأ عند أول تشغيل (لا كلمات افتراضية)، إجبار التغيير، حد لمحاولات الدخول.
- **CSRF + CORS** محصّنان للشبكة المحلية، جلسات موقّعة، تسجيل تدقيق شامل.
- `allowBackup=false` على أندرويد (لا نسخ سحابي لبيانات النظام).
- المراجع: [سياسة الأسرار](docs/secrets-policy-ar.md) · [إدارة المفاتيح](docs/key-management-ar.md) · [تقرير التقوية](docs/security-hardening-report-ar.md).

```bash
pnpm install --ignore-scripts
pnpm run typecheck
pnpm run build
pnpm run lint

# تشغيل التطبيق محلياً (Windows)

# بناء الحزم
node scripts/build-protected-web.mjs windows

./release-artifacts/scripts/reassemble-electron.ps1     # إعادة تجميع حزمة ويندوز
```

## 🆕 الإصدار 5.0.6 — الميزات والإمكانيات

### الحاكمية والصلاحيات
- ثلاث صلاحيات: **مدير** · **أمين مستودع** · **مراقب**، مفروضة على الخادم.
- تعريفات الكتالوج والبيانات المرجعية للمدير فقط؛ أمين المستودع ينفّذ العمليات اليومية.

### الكتالوج والوحدات
- شاشة كتالوج مركزي (`/catalog`): وحدات · مستودعات · مواد · تجهيزات.
- وحدات قياس معيارية + أداة توحيد الوحدات النصّية القديمة.
- أرشفة بدل الحذف · رمز تجهيز فريد · منع تغيير رمز/وحدة مادة لها حركات.

### المخزون والعمليات
- إدخال · إخراج · تسليم · عهد · إرجاع عهد · مرتجع مركزي · تلف · **تسوية جرد**.
- دفعات + **FEFO** · حد أدنى · تنبيهات نقص/انتهاء صلاحية · مؤشرات نفد/راكد.
- **مركز المخزون** (`/inventory`): مؤشرات + نواقص + حالة التجهيزات + لوحة ترصيد.

### تعدد المستودعات والتحويلات
- نموذج مستودعات كامل (رمز · نوع مركزي/فرعي · ربط الجهاز بمستودعه) + **القواعد الخمس** أعلاه.
- ترقيم مستندات `كود-نوع-سنة-تسلسل` لا يتصادم بعد دمج المواقع.
- دورة تحويل كاملة (+ إيصال مبدئي) ومستند طباعة A4 وفروق استلام بأسباب.
- رصيد لكل **(صنف × مستودع)** + **إجمالي موحّد** + **تقرير مقارنة المواقع**.

### الاستيراد والتصدير
- **مدخل واحد «استيراد الكتالوج»:** قالب التعريفات (مواد + تجهيزات بكمية ومستودع) + قالب **الأرصدة الافتتاحية لكل مستودع**.
- معاينة بأثر كل صف · اعتماد · تراجع عن دفعة · حد 2000 صف.

### المزامنة (بلا سيرفر مركزي)
- حزم `.dme-sync` مشفّرة (AES-256-GCM) تُنقل بـUSB/مجلد شبكة.
- ثقة بمفاتيح Ed25519 · كشف تعارضات وحلّها · منع تكرار آمن.

### النسخ الاحتياطي والأمان
- نسخ مشفّرة + قائمة نسخ + معاينة واستعادة بنقطة زمنية + تراجع.
- سجل تدقيق شامل + **تدقيق حقلي (قبل/بعد)** + حماية CSRF + حدّ لمعدّل الطلبات.

### التفعيل والمنصّات
- **Windows**: Portable + Protected · **Android**: Offline + Protected.
- ترخيص مُوقّع Ed25519 مخصّص للجهاز (المنصة + المعرّف + إصدار 5.0.6) + **حزمة تفعيل** تولّد تراخيص Windows/Android.
- **صفحة مساعدة موسّعة** داخل التطبيق (16 قسماً، حسب الدور، خريطة الأزرار، إعداد المستودع، التقارير/الطباعة/التصدير).
