## 🚀 البدء السريع (ويندوز)

1. نزّل `Windows-Protected.zip` من صفحة الإصدارات
2. فك الضغط وشغّل **`مستودعات مديرية صحة دمشق.exe`**
3. عند أول تشغيل: أنشئ حساب المدير (شاشة «إعداد حساب المدير»)
4. ستظهر شاشة **«نسخة محمية»** بمعرّف الجهاز — انسخه
5. أرسل معرّف الجهاز إلى مسؤول النظام لإصدار الترخيص
6. الصق الترخيص الذي استلمته في التطبيق → **«تفعيل التطبيق»** — انتهى

> التفعيل يُخزَّن في قاعدة بيانات الجهاز (ليس في المتصفح): بعد التفعيل يفتح النظام مفعّلاً من كل متصفحات الشبكة المحلية.

### أندرويد

ثبّت `Android-Protected.apk` (اسمح بـ «مصادر غير معروفة») → أرسل معرّف الهاتف إلى مسؤول النظام واستلم الترخيص لإتمام التفعيل محلياً.

### الوصول من المتصفح (LAN)

| الخدمة | المنفذ | مثال |
|---|---|---|
| الواجهة | **41790** (ثابت) | `http://192.168.1.55:41790` |
| API | **41789** (ثابت) | `http://192.168.1.55:41789/api/healthz` |

اسمح للمنفذين في جدار الحماية مرة واحدة:

```bat
netsh advfirewall firewall add rule name="DME Web 41790" dir=in action=allow protocol=TCP localport=41790
netsh advfirewall firewall add rule name="DME API 41789" dir=in action=allow protocol=TCP localport=41789
```

اعرف عنوان الجهاز بـ `ipconfig` (سطر IPv4). المنفذان ثابتان على كل الأجهزة؛ يتحولان لعشوائي فقط عند تشغيل نسختين معاً على نفس الجهاز.

## 🔄 المزامنة بين الأجهزة

| السيناريو | الطريقة |
|---|---|
| ويندوز ↔ ويندوز | «المزامنة» → «مزامنة شبكية مباشرة» بعنوان API الطرف الآخر `:41789` + بيانات مشرفه — النداء ثنائي الاتجاه. أو ملفات `.dme-sync` |
| أندرويد ↔ أندرويد | تصدير حزمة → مشاركة الملف → استيراد وتطبيق (ثم العكس) |
| أندرويد ↔ ويندوز | الهاتف يبدأ «مزامنة شبكية مباشرة» بعنوان الويندوز `:41789` — أو ملفات |

الاستيراد مضمون ضد التكرار (كل تغيير بمعرّف فريد)، والتعارضات تظهر في «طابور التعارضات» لقرارك (اعتماد/رفض/تأجيل) مع تسجيل في التدقيق. التفاصيل الكاملة في [دليل العمليات](docs/operations.md) و[دليل المستخدم](docs/user-guide-ar.md).

## 🔐 الأمان

- **ترخيص Ed25519** بمفاتيح منفصلة لكل منصة — المفتاح الخاص خارج المستودع (`release-secrets/`، غير مرفوع)
- **حزم النسخ والمزامنة مشفرة** بكلمة مرور لا يعرفها سوى المرسل والمستقبل
- **كلمة مرور المدير**: تُنشأ عند أول تشغيل (لا كلمات مرور افتراضية)، إجبار التغيير، حد لمحاولات الدخول
- **CSRF + CORS محصّنان** لنطاقات الشبكة المحلية، جلسات موقعة، تسجيل تدقيق شامل
- **seed مضمون**: لا بيانات وهمية تدخل الإنتاج؛ البيانات الفعلية تُستورد من Excel

## 🛠️ التطوير من المصدر

```bash
pnpm install --ignore-scripts   # (Windows: تجاوز سكربت preinstall)
pnpm run typecheck              # كل الحزم
pnpm run build                  # بناء كامل
pnpm test
pnpm lint
pnpm test:e2e

# PostgreSQL المستضاف — قبل تشغيل API
pnpm db:migrate
pnpm db:readiness

# تطوير يومي (أدلة ضمن المستودع)
./start-dev.ps1                 # API + واجهة التطوير
./stop-dev.ps1

# بناء حزم الإصدار
node scripts/build-protected-web.mjs windows          # واجهة النسخة المحمية
pnpm --filter @workspace/api-server run build:protected
node scripts/release-dry-run.mjs                         # تحقق إصدار قابل للتتبع + checksums
./android/gradlew assembleRelease                         # بناء Android (يتطلب Android SDK/JDK)
```

اختبارات CI تعمل تلقائياً عبر `.github/workflows/ci.yml`، وتوقف الدمج عند
فشل النوع أو البناء أو الاختبار أو lint أو E2E. راجع
`docs/ci-guide-ar.md` و`docs/database-runbook-ar.md` لمساري التشغيل.

## 🆕 الإصدار 5.0.3 — الميزات والإمكانيات

### الحاكمية والصلاحيات
- ثلاث صلاحيات: **مدير** · **أمين مستودع** · **مراقب**، مفروضة على الخادم.
- تعريفات الكتالوج والبيانات المرجعية للمدير فقط؛ أمين المستودع ينفّذ العمليات اليومية.

### الكتالوج والوحدات
- شاشة كتالوج مركزي (`/catalog`): وحدات · مستودعات · مواد · تجهيزات.
- وحدات قياس معيارية + **أداة توحيد** الوحدات النصّية القديمة.
- أرشفة بدل الحذف · رمز تجهيز فريد · منع تغيير رمز/وحدة مادة لها حركات.

### المخزون والعمليات
- إدخال · إخراج · تسليم · عهد · إرجاع عهد · مرتجع مركزي · تلف · **تسوية جرد**.
- دفعات + **FEFO** · حد أدنى (عام) · تنبيهات نقص/انتهاء صلاحية.
- **مركز المخزون** (`/inventory`): مؤشرات + نواقص + حالة التجهيزات + **لوحة ترصيد**.

### تعدد المستودعات والتحويلات
- نموذج مستودعات كامل: رمز · نوع (مركزي/فرعي) · ربط الجهاز بمستودعه.
- **ترقيم مستندات** `كود-نوع-سنة-تسلسل` لا يتصادم بعد دمج المواقع.
- **دورة تحويل** كاملة: طلب ← إرسال ← استلام (+ إيصال مبدئي) ومستند طباعة A4.
- رصيد لكل **(صنف × مستودع)** + **إجمالي موحّد** للمدير.

### الاستيراد والتصدير
- قالب كتالوج + قالب رصيد افتتاحي · معاينة بأثر كل صف · اعتماد · **تراجع عن دفعة**.
- سجل دفعات استيراد مع تدقيق كامل.

### المزامنة (بلا سيرفر مركزي)
- حزم `.dme-sync` **مشفّرة** (AES-256-GCM) تُنقل بـUSB/مجلد شبكة.
- ثقة بمفاتيح **Ed25519** · نواقل · كشف تعارضات وحلّها · منع تكرار آمن.
- **لوحة إدارة المزامنة**: هوية الجهاز · الصادر المعلّق · التعارضات · العُقد الموثوقة.

### النسخ الاحتياطي والأمان
- نسخ مشفّرة + قائمة نسخ + معاينة واستعادة بنقطة زمنية + تراجع.
- سجل تدقيق شامل + **تدقيق حقلي (قبل/بعد)** + حماية CSRF + حدّ لمعدّل الطلبات.

### المنصّات والإصدارات
- **Windows**: نسخة محمية (تفعيل بترخيص) + نسخة عادية (Portable).
- **Android**: تطبيقا Offline وProtected (قاعدة بيانات داخلية).
- ترخيص مُوقّع Ed25519 مخصّص للجهاز · مجموعة تفعيل كاملة تولّد تراخيص Windows/Android.
