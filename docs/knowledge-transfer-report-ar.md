# تقرير نقل المعرفة — المرحلة الخامسة

**الحالة:** قالب تنفيذ وقبول  
**القاعدة:** لا يُغلق نقل المعرفة بتسليم الوثيقة فقط؛ يجب تنفيذ التمرين من شخص
ثانٍ على نسخة نظيفة وتسجيل الدليل.

## نطاق التمرين

يستخدم المتدرب نسخة اختبارية وبيانات صناعية فقط، ولا يحصل على أسرار الإنتاج.
المراجع يراقب النتيجة ولا يقود الأوامر.

| # | التمرين | دليل القبول | الحالة |
|---:|---|---|---|
| 1 | إنشاء clone وتثبيت lockfile | `pnpm install --frozen-lockfile` ناجح | معلّق على التنفيذ البشري |
| 2 | بناء API والواجهة | `pnpm build` ناجح | قابل لإعادة التنفيذ |
| 3 | تشغيل Desktop | `healthz` يعرض قاعدة جاهزة | قابل لإعادة التنفيذ |
| 4 | إنشاء مدير تجريبي | تسجيل الدخول في قاعدة مؤقتة | معلّق على التنفيذ البشري |
| 5 | تشغيل PostgreSQL | migration ثم readiness ناجحان | يتطلب PostgreSQL اختباريًا |
| 6 | تصدير واستيراد حزمة | checksum صحيح، لا أسرار، تقرير واضح | قابل لإعادة التنفيذ |
| 7 | تشخيص عطل مصطنع | تحديد runbook والسبب دون تخمين | معلّق على التنفيذ البشري |
| 8 | rollback اختباري | عودة قاعدة الاختبار دون لمس المصدر | يتطلب نسخة اختبارية |
| 9 | قراءة سجل حادثة | تحديد الأثر والإجراء والقرار | معلّق على التنفيذ البشري |
| 10 | تسليم المعرفة | توقيع المتدرب والمراجع | معلّق |

## قرار القبول

لا يُعتمد النقل إلا إذا:

- لم يستخدم المتدرب بيانات أو أسرار إنتاج.
- أعاد تنفيذ الأوامر من نسخة نظيفة.
- فسّر حالة المزامنة والتعارض والنسخة الاحتياطية.
- عرف متى يوقف العملية ومتى يستخدم rollback.
- وقع المتدرب والمراجع على السجل.
