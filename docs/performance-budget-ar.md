# ميزانية أداء الواجهة

## الغرض

تمنع هذه البوابة تضخم ملفات JavaScript وCSS في نسخة الويب دون ملاحظة. لا
تستبدل اختبار الأجهزة الضعيفة أو اختبار Android؛ هي فحص مبكر لحجم مخرجات Vite.

## الحدود

| الحد | القيمة | السلوك |
|---|---:|---|
| تنبيه | 500 KiB للملف | يظهر في سجل CI ولا يفشل البناء |
| أقصى حجم | 600 KiB للملف | يفشل `pnpm performance:check` |

يُفحص كل ملف `.js` و`.css` تحت `artifacts/web/dist/public/assets` بعد البناء،
ولا تُفحص sourcemaps ضمن الميزانية. يمكن تغيير الحدود مؤقتاً عبر
`BUNDLE_WARN_KB` و`BUNDLE_MAX_KB`، لكن أي استثناء يجب أن يسجل في تقرير الإصدار
مع سبب وموعد مراجعة.

## التشغيل

```bash
pnpm build
pnpm performance:check
```

تشغل GitHub Actions الفحص بعد البناء مباشرة. عدم وجود مخرجات الواجهة أو تجاوز
الحد الأقصى يفشل البوابة بدلاً من إخفاء المشكلة.
