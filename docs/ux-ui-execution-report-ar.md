# تقرير تنفيذ خطة UX/UI والتحقق المحلي

التاريخ: 2026-09-05

## النطاق

تم تشغيل المشروع من الفرع `master` المرتبط بمستودع GitHub عبر HTTPS:

- المستودع: `https://github.com/ibrahims78/Damascus-Health-Directorate`
- الفرع: `master`
- OAuth: غير مستخدم
- بيانات الإنتاج والأسرار: خارج نطاق الاختبار

النسخة المحلية تتبع `origin/master`. تم تنفيذ التغييرات الحالية محليًا فقط،
ولم يتم دفعها إلى GitHub بعد لأن صلاحية الكتابة إلى المستودع لم تُثبت بعد.

## ما تم تنفيذه

### تقسيم حزمة الواجهة

تم تحويل صفحات التطبيق إلى تحميل مرحلي عند فتح المسار، مع إبقاء الغلاف العام
وحالات التحميل ثابتة:

- أصبحت الصفحة الأولى لا تحمل كل صفحات العمليات والإعدادات والمزامنة دفعة واحدة.
- تم الحفاظ على المسارات الحالية وسلوك الحماية والصلاحيات.
- ظهر لكل صفحة chunk مستقل في build.
- انخفضت أكبر حزمة تطبيق رئيسية من نحو 1.49MB إلى نحو 445KB بعد التصغير.
- بقيت حزمة Excel منفصلة حتى لا تؤخر فتح التطبيق.

### اختبارات الخادم المعزولة

تم تحديث مشغل الاختبارات ليستخدم مجلدات PGlite مؤقتة ومنافذ مستقلة عن workflow
الرئيسي. المنافذ قابلة للضبط عبر `E2E_PORT_A` و`E2E_PORT_B`
و`E2E_FRESH_PORT`.

النتائج:

- مزامنة عقدتين: **51 ناجحًا، 0 فشل**
- الأمان وCSRF والجلسات وتحديد المحاولات: **13 ناجحًا، 0 فشل**
- كلمات مرور الوضع offline والتوافق الخلفي: **8 ناجحًا، 0 فشل**

تشمل الاختبارات إنشاء مواد وتجهيزات محلية، حركات إدخال، FEFO، تعارضات
المزامنة، إعادة التسليم، التكرار، التوقيعات، CSRF، الجلسات، وتدفق تغيير
كلمة المرور الإجباري. تُحذف مجلدات الاختبار المؤقتة بعد انتهاء التشغيل.

## التحقق المحلي

| الفحص | النتيجة |
|---|---|
| `pnpm run typecheck` | ناجح |
| `pnpm test` | 35 اختبارًا ناجحًا |
| `pnpm run build` | ناجح |
| `pnpm run lint` | 0 أخطاء، مع تحذيرات unused قديمة |
| `bash scripts/ci-e2e.sh` | جميع مجموعات الاختبار ناجحة |
| `GET /api/healthz` | 200 |
| إعداد حساب محلي | ناجح |
| طلب `/api/auth/me` دون جلسة | 401 متوقع |
| طلبات API أساسية مع جلسة اختبار | 200 |
| شاشة الدخول RTL | تمت مراجعتها بصريًا |
| صفحة 404 العربية | تمت مراجعتها بصريًا |

تم إنشاء حساب اختبار محلي داخل `.damascus-data` فقط لاختبار الإعداد والدخول.
لا يُستخدم هذا الحساب في الإنتاج، ولا تُحفظ كلمة مروره في المستودع أو التقرير.

## حالة workflow

`Start application` يعمل ويخدم:

- واجهة الويب على المنفذ 5000
- API المحلي على المنفذ 8080

سجلات التشغيل خالية من أخطاء بدء مانعة. رسائل 401 التي تظهر عند فتح الواجهة
بدون جلسة هي السلوك المتوقع قبل تسجيل الدخول وليست فشلًا في الخادم.

## القيود المتبقية

- لم تتوفر بيئة Windows فعلية أو محاكي/جهاز Android؛ لذلك لم يُعتمد الاختبار
  النهائي الخاص بالطباعة واللمس والدوران كاختبار أجهزة.
- تم التحقق من حالات الويب المتاحة عبر preview وHTTP ولقطات الواجهة، لكن لا
  توجد أداة تفاعل متصفح مصادق كاملة في بيئة التنفيذ الحالية لإثبات كل نقرة
  يدوية داخل جميع المسارات.
- لم تُلمس قاعدة بيانات الإنتاج أو أي سر من أسرار Replit.

قرار التنفيذ المحلي: **جاهز للدمج بعد مراجعة صلاحية الدفع إلى GitHub، مع بقاء
اعتماد Windows/Android الفعلي قبل إطلاق النسخة النهائية.**
