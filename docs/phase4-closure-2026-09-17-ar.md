# تقرير إغلاق المرحلة 4 — الإصدارات والبناء والتوثيق

## النطاق

أصبح `package.json` مصدر النسخة، وأضيف فحص/مزامنة حتمية لنقاط العرض، وفحص
مسارات وروابط الوثائق، ودليل إصدار يربط البناء بالـ commit وchecksums.

## التغييرات

- `scripts/sync-version.mjs` للتحقق والمزامنة.
- `scripts/release-dry-run.mjs` لإثبات مخرجات البناء وSHA256.
- `scripts/docs-check.mjs` لمنع روابط المستودع القديم والمسارات المحذوفة.
- تحديث README وREADME التطوير وCHANGELOG للمستودع والإصدار النشطين.
- استبدال تعليمات مسارات الإصدار القديمة بمسارات موجودة أو بدليل الإصدار.

## القيود المفتوحة

إنشاء Release فعلي ورفع الحزم الثنائية خارج نطاق هذا التغيير؛ المطلوب هنا
قابلية إعادة البناء والتحقق والتوثيق دون رفع ملفات كبيرة أو أسرار إلى Git.
