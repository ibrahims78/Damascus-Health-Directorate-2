# ADR-001: فصل PGlite عن PostgreSQL

**الحالة:** معتمد  
**التاريخ:** 2026-09-17

## القرار

يستخدم Desktop وAndroid وضع PGlite بقاعدة محلية ومخطط `desktop-schema.sql`.
يستخدم مسار الاستضافة PostgreSQL مع migrations Drizzle. لا يبدل التطبيق بين
المحركين ضمن تشغيل واحد، ولا تطبق الخدمة المستضافة DDL تلقائيًا عند الإقلاع.

## السبب

يحتاج التشغيل غير المتصل إلى قاعدة محلية قابلة للنقل، بينما يحتاج الخادم
المستضاف إلى migrations قابلة للتدقيق وقراءة جاهزية قبل فتح المنفذ. الخلط بين
المسارين يجعل فشل المخطط صعب التشخيص وقد يسبب كتابة على قاعدة غير مهيئة.

## الآثار

- يجب اختبار المسارين مستقلين.
- كل تغيير schema يحدّث تعريف Drizzle وmigration ومخطط Desktop عند الحاجة.
- `healthz` يوضح المحرك ومصدر المخطط.
