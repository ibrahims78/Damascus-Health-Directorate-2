# ADR-003: المزامنة دون خادم مركزي

**الحالة:** معتمد  
**التاريخ:** 2026-09-17

## القرار

التقارب الأساسي peer-to-peer أو عبر ملف `.dme-sync` مشفر. الخادم الوسيط
والـrelay اختياريان لنقل البايتات ولا يصبحان مصدر الحقيقة. كل عقدة تحتفظ بسجل
تغييرات ومتجه معرفة وقرارات تعارض محلية.

## السبب

يجب أن يعمل النظام في مواقع ضعيفة الاتصال أو بلا إنترنت، مع إمكانية نقل ملف
بوسيلة يدوية. الاعتماد على مركز دائم يضيف نقطة فشل ويخالف متطلبات التشغيل
المحلي.

## الآثار

- التبادل ليس تلقائيًا؛ يحدده المستخدم أو جدول تشغيل معتمد لاحقًا.
- يجب حفظ `baseVector` و`lastVector` مع كل حزمة.
- لا يجوز حذف سجل التغيير أو tombstone قبل التأكد من تقارب كل النظائر.
