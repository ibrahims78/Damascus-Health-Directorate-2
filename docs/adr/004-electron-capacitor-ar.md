# ADR-004: Electron وCapacitor كحدود منصة

**الحالة:** معتمد  
**التاريخ:** 2026-09-17

## القرار

تشارك Windows/Electron وAndroid/Capacitor منطق الواجهة والعقود، بينما تبقى
قاعدة البيانات وطبقة التخزين الخاصة بالمنصة خلف حدود واضحة. لا تُضاف معالجة
منصة إلى API المشترك إذا كان يمكن وضعها في adapter محلي.

## السبب

يحتاج Desktop إلى PGlite ومسار ملفات محلي، ويحتاج Android إلى تخزين وملفات
يوافقان قيود الهاتف. مشاركة العقود تقلل اختلاف المزامنة، وفصل adapters يمنع
تسرب افتراضات نظام التشغيل إلى الخادم.

## الآثار

- يجب اختبار Web/Desktop وAndroid Offline كل على حدة.
- ملف `.dme-sync` هو عقد التبادل المشترك.
- بناء Android لا يثبت صلاحية تثبيت Windows والعكس.
