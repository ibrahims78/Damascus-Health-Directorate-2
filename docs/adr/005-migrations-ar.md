# ADR-005: سياسة migrations

**الحالة:** معتمد  
**التاريخ:** 2026-09-17

## القرار

مسار PostgreSQL هو forward-only بعد مراجعة SQL. يسبق migration كبيرة نسخة
احتياطية وفحص readiness، ويكون rollback عبر migration تعويضية أو استعادة
اختبارية مع قرار مسؤول البيانات؛ لا يستخدم حذف عشوائي أو `push-force`.

## السبب

البيانات التشغيلية لا تسمح بإخفاء أثر تغيير schema. rollback الآلي العام قد
يتلف بيانات أضيفت بعد migration، لذلك يلزم قرار حسب التغيير.

## الآثار

- كل migration تحمل سببًا واختبارًا وخطة تعويض.
- لا يفتح API المستضاف قبل نجاح readiness.
- مسار Desktop يحدّث `desktop-schema.sql` بطريقة متوافقة.
