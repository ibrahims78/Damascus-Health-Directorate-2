# ADR-006: النسخ والاستعادة

**الحالة:** معتمد  
**التاريخ:** 2026-09-17

## القرار

تستخدم النسخة التشغيلية صيغة `.dme-sync` المشفرة والمضغوطة مع checksum وMAC.
الاستعادة تمر بثلاث مراحل: inspect، dry-run، ثم confirm صريح. الاستعادة ليست
حذفًا شاملًا؛ merge هو المسار الافتراضي، وfull يحتاج موافقة منفصلة وبيئة
اختبارية قبل الإنتاج.

## السبب

وجود ملف نسخة لا يثبت قابليته للاستعادة. الفصل بين الفحص والتأكيد يمنع تطبيق
حزمة تالفة أو على قاعدة خاطئة دون قرار واضح.

## الآثار

- كلمة مرور الحزمة لا تحفظ في الكتالوج أو السجل.
- يجب اختبار كلمة مرور خاطئة وحزمة معدلة وrollback.
- يبقى المصدر دون تعديل حتى اكتمال الفحص والتأكيد.
