# تقرير إغلاق المرحلة 3 — الأمان والخصوصية وسلسلة التوريد

## النطاق

أزيلت قناة البلاغ العامة والبيانات الشخصية من السطح العام، ووُحّدت روابط
المستودع، ومُنع fallback السرّي الثابت، وأضيف فحص للحالة الحالية وتاريخ Git.

## التغييرات

- قناة البلاغ: GitHub Security Advisory الخاص بالمستودع.
- الأسرار: `SESSION_SECRET` مطلوب لـ PostgreSQL، ولا يوجد سر ثابت بديل.
- مفاتيح Ed25519 الخاصة خارج Git، والمفتاح العام فقط قابل للتوزيع.
- فحوص آلية: `pnpm security:scan` و`pnpm audit --prod --audit-level=high`.
- توثيق: سياسة الأسرار، إدارة المفاتيح، ودليل حادثة أمنية.
- وُحّدت حزمة `xlsx` في أدوات الاستيراد مع النسخة `0.20.3` المستخدمة في
  الواجهة، وثُبّت `qs` على النسخة المصححة المتوافقة مع Express؛ يعيد فحص
  التبعيات الحالي `No known vulnerabilities found`.

## القيود المفتوحة

يحتاج اعتماد قناة الدعم المؤسسية ومالكي الأسرار والبديل إلى أسماء تشغيلية من
صاحب المشروع قبل اعتماد G2 النهائي. لا يوقف ذلك إزالة البيانات الشخصية أو
اختبار المستودع الآلي.
