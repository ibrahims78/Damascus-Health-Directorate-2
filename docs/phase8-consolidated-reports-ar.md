# المرحلة 8 — التقارير الموحّدة والطباعة (تنفيذ + توثيق)

**المشروع:** مديرية صحة دمشق — الإصدار **4.3.0** (المرحلة 8)
**التاريخ:** 2026-09-14
**الحالة:** ✅ منفَّذة ومُختبرة

---

## 1) الهدف
رؤية **موحّدة** لكل المواقع للمدير (مع إجمالي وتفصيل)، و**مستندات قابلة للطباعة** لعمليات التحويل —
مع الالتزام بقرار «الفرع يرى رصيده فقط».

## 2) ما تغيّر

### أ) الخادم
- **`GET /api/reports/consolidated`** (للمدير فقط):
  - **إجماليات**: عدد الأصناف · التجهيزات · إجمالي الكميات · **أصناف تحت الحد الأدنى** · عدد المستودعات.
  - **صف لكل مستودع**: nombre الأسطر · إجمالي الكمية · عدد الأصناف تحت الحد الأدنى **محتسبة لكل موقع** على حدة
    (الحد الأدنى عام كما تقرّر).
- البيانات مجمّعة من **سجل الدفعات** (مصدر الحقيقة للمخزون المخزَّن) مع مستودعاتها.

### ب) الواجهة
- **قسم «التقارير الموحّدة»** في **مركز المخزون** (يظهر للمدير): جدول لكل مستودع + إجماليات.
- **صفحة التحويلات** `/transfers`: سجل + إنشاء طلب + إجراءات (إرسال/استلام/رفض/إلغاء) + زر **طباعة**.
- **مستند تحويل للطباعة** `/transfers/:id/print`: صفحة A4 مرتّبة (ترويسة المديرية · بيانات التحويل · جدول السطور ·
  خانة توقيع أمين الإرسال والاستلام والمدير) مع `window.print()`؛ تُطبع بلا عناصر الواجهة (`print:hidden`).

## 3) الاختبار
```bash
node docs/tests/phase8-consolidated-tests.mjs
```
**النتيجة:** ✅ **10/10 نجحت** — منها:

- **التنبيه للحد الأدنى يُحتسب لكل مستودع** (2 عند حدّ أدنى 8 ورصيد 5 في كل موقع).
