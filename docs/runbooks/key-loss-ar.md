# Runbook: فقد مفتاح التوقيع أو الثقة

## الإجراء الفوري

1. أوقف التبادل مع العقدة المتأثرة.
2. لا تحذف سجل العقدة أو الحزم؛ احتفظ بها للتحقيق.
3. أبلغ مسؤول الأمان ومسؤول التشغيل.
4. ألغِ العقدة في `sync_trusted_nodes` مع حفظ سبب ووقت الإلغاء.
5. أنشئ زوج مفاتيح جديدًا خارج المستودع.
6. أعد الاقتران عبر رمز مؤقت، وشارك المفتاح العام فقط.
7. أعد إرسال الحزم التي فشل التحقق منها بعد فحص مصدرها.

## ممنوعات

لا تستخرج المفتاح الخاص من نسخة احتياطية عادية، ولا تضعه في issue أو سجل دعم
أو ملف إعدادات مشترك. إذا شككت بتسربه، اعتبره ملغى لا قابلًا للاسترداد.
