# Runbook: فشل migration

## قبل التصرف

سجل اسم migration، commit، وقت البداية، ورسالة الخطأ. لا تعاود تشغيل migration
عمياء إذا كانت العملية غير معلومة الحالة.

## الإجراء

1. افحص `drizzle.__drizzle_migrations`.
2. تحقق هل تغيرت الجداول جزئيًا.
3. لا تشغل API على مخطط جزئي.
4. استشر ملف migration وخطة التعويض في ADR المرتبط.
5. إن كانت العملية قابلة لإعادة التنفيذ، نفذها بعد أخذ نسخة.
6. إن لم تكن قابلة لإعادة التنفيذ، استعد نسخة اختبارية أولًا وابنِ migration
   تعويضية؛ لا تعدل سجل migrations يدويًا إلا بقرار موثق.

## إغلاق الحادثة

يجب أن يثبت `db:readiness` النجاح، وأن ينجح اختبار API وhealthz، وأن يضاف
الدليل إلى سجل الحادثة.
