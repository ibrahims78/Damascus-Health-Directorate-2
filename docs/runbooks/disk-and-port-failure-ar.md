# Runbook: امتلاء القرص أو تعطل المنفذ

## امتلاء القرص

أوقف التصدير أو المزامنة قبل فشل الكتابة. افحص المساحة، حجم `.damascus-data`
والحزم المؤقتة، ثم انقل النسخ إلى تخزين معتمد بعد التحقق من checksum. لا تحذف
آخر Full Backup سليم ولا ملفات قاعدة البيانات الحية يدويًا.

## تعطل المنفذ

1. حدد العملية المالكة للمنفذ.
2. لا توقف عملية مجهولة قبل تسجيل PID والأمر.
3. استخدم منفذًا معتمدًا أو أوقف Workflow المكرر.
4. تحقق من `healthz` بعد التشغيل ومن أن الواجهة تستخدم `/api` النسبي.
