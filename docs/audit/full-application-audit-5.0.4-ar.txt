 3. تجهيز المشروع والفحوص الأساسية
====================================================================

نفذ الأوامر التالية من جذر المشروع بالترتيب:

    git status --short --branch
    pnpm install --frozen-lockfile
    pnpm version:check
    pnpm typecheck
    pnpm build
    pnpm test

النتائج المطلوبة:

[ ] ملف القفل مطابق ولا توجد تغييرات غير مقصودة.
[ ] version:check ناجح، والإصدار 5.0.4 وAndroid versionCode 504.
[ ] typecheck ناجح لكل مشاريع المكتبات وAPI والواجهة والسكريبتات.
[ ] build ناجح للخادم والواجهة.
[ ] جميع اختبارات Vitest ناجحة.
[ ] لا توجد أخطاء TypeScript.

تحذيرات لا تمنع النجاح، لكنها تسجل:

[ ] تحذيرات حجم chunks.
[ ] تحذيرات sourcemap.
[ ] أي تحذير آخر مع تفسيره.

اختبارات إضافية:

    pnpm lint
    pnpm docs:check
    pnpm performance:check
    pnpm security:scan
