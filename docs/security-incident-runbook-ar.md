# دليل حادثة أمنية

## 1. الاحتواء

1. افتح بلاغًا خاصًا عبر [GitHub Security Advisory](https://github.com/ibrahims78/Damascus-Health-Directorate-2/security/advisories/new).
2. أوقف النشر أو الجدولة المتأثرة، ولا تحذف السجلات الأصلية.
3. ألغِ السر أو المفتاح المتأثر من مدير الأسرار.
4. حدّد البيئات والإصدارات والمواقع المتأثرة باستخدام commit وchecksum.

## 2. التحقيق

سجّل وقت الاكتشاف، مصدر البلاغ، الأثر، السجلات ذات الصلة، نطاق البيانات،
والإجراء المؤقت. لا تنسخ بيانات إنتاج حقيقية إلى البلاغ أو الاختبارات.

## 3. الإصلاح والتحقق

```bash
pnpm install --frozen-lockfile
pnpm security:scan
pnpm typecheck
pnpm test
pnpm build
pnpm test:e2e
```

لا يُعلن الإصلاح قبل مراجعة مستقلة واختبار المسار السلبي وتحديث `CHANGELOG.md`
وإصدار checksum جديد.

## 4. الإفصاح والإغلاق

يُتفق على الإفصاح بعد توفر التخفيف والإصدار المصحح. يجب أن يتضمن تقرير الإغلاق
الأثر، السبب، الإصدارات المتأثرة، الإصلاح، وما يمنع تكرار الحادثة.
