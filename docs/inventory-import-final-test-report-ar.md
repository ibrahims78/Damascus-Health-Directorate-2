## مصفوفة الأخطاء والحدود

اختبارات العقد المشترك تغطي الاسم القصير، الوحدة الفارغة أو غير المعروفة،
التصنيف غير المعروف، الكمية السالبة أو العشرية، التاريخ غير الصالح، الرأس
المجهول أو المكرر، رمز المادة المكرر، الدفعة اليتيمة، والدفعة المكررة. كما
يرفض API جسمًا كبيرًا، وتتحقق الواجهة من ملف أكبر من 10 ميغابايت وتعرض فشل
القراءة للامتداد أو الملف التالف.

## قرارات الفشل

- لا يحفظ الاستيراد جزئيًا عند وجود خطأ حرج؛ يعاد الفحص داخل معاملة الخادم.
- لا يغير `upsert` رصيد مادة موجودة.
- لا تنشئ إعادة رفع التصدير دفعات أو حركات إضافية.
- workflow الرسمي هو `Start application` لأنه يشغل API على `8080` والواجهة على
  `5000`. لا يشغل workflow `artifacts/api-server: API Server` بالتوازي؛ فهو
  محاولة خادم ثانية على نفس المنفذ وقد يفشل بـ`EADDRINUSE`.

## قرار الإغلاق

الجزء البرمجي واختبارات القبول الآلية **مكتملة وناجحة**. تبقى موافقة تشغيلية
يدوية على فتح النموذج في برامج المكتب الفعلية وقياس أداء ملفات كبيرة قبل إعلان
اعتماد تشغيلي نهائي ببيانات مستودع حقيقية.
