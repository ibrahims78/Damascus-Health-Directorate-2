# خط أساس أداء المزامنة

## منهج القياس

يقيس `pnpm sync:performance` مرحلة تجهيز البيانات الاصطناعية فقط: بناء متجهات
وتغييرات، ترتيبها، JSON serialization، وحساب SHA-256. لا يخلط ذلك بزمن
الشبكة أو القرص أو PostgreSQL.

الأحجام:

| الحجم | التغييرات | الاستخدام |
|---|---:|---|
| S | 100 | مكتب صغير أو smoke |
| M | 1,000 | Pilot |
| L | 10,000 | حد اختبار قبل التوسع |

يسجل الأمر `elapsedMs` و`payloadBytes` و`changesPerSecond` لكل حجم في stdout.
لا تُرفع ملفات بيانات أو أسرار؛ القيم مولدة في الذاكرة.

## معايير قبول أولية

هذه حدود مقارنة وليست ضمانًا لجهاز إنتاج:

- لا فشل أو timeout عند S/M/L.
- لا يتجاوز payload حد API المعلن للحزمة.
- لا يزيد الزمن خطيًا بشكل أسوأ من O(n log n) بسبب الترتيب.
- لا يطبع القياس payload أو كلمة مرور.
- يكرر القياس على نفس commit مع تسجيل Node وpnpm والذاكرة إن كان القرار
  متعلقًا بالأداء.
