# دليل CI المحلي

## النطاق

هذا الدليل يصف بوابات المرحلة الأولى. كل أمر يعمل من جذر المستودع وعلى
نسخة تعتمد على `pnpm-lock.yaml`.

## التثبيت وإصدارات الأدوات

```bash
node --version
pnpm --version
pnpm install --frozen-lockfile
```

الإصدار المعلن لـ pnpm هو `10.26.1` كما هو مثبت في `package.json` وWorkflow
GitHub Actions. يثبت CI Node.js 22؛ بيئة Replit الحالية تستخدم Node.js 20
والأوامر نفسها يجب أن تنجح عليها.

## البوابات المحلية

```bash
pnpm typecheck
pnpm build
pnpm test
pnpm lint
pnpm test:e2e
```

يشغّل `pnpm typecheck` مراجع TypeScript للمكتبات أولاً مع `--force` حتى لا
تُستخدم ملفات `dist` قديمة، ثم يفحص API والواجهة والسكريبتات وعقود النسخ.
يشغّل `pnpm build` حزمة API ثم حزمة الويب. الاختبارات الموحدة هي Vitest،
واختبارات التكامل الحية هي `pnpm test:e2e`.

## قراءة السجلات

- فشل `typecheck`: راجع اسم المجموعة المطبوعة قبل أول خطأ TypeScript.
- فشل `build`: افحص أولاً مسار الحزمة (`api` أو `web`) ثم أعد الأمر منفرداً.
- فشل `test`: لا تستخدم `--passWithNoTests`؛ عدد الملفات والاختبارات يجب أن
  يظهر في نهاية Vitest.
- فشل `lint`: الأخطاء توقف CI. توجد تحذيرات legacy معلنة في `eslint.config.js`
  ولا تعتبر نجاحاً نظيفاً؛ يجب تخفيضها تدريجياً قبل حذف الاستثناءات.
- فشل `test:e2e`: راجع سجلات التشغيل المؤقتة وتأكد من عدم استخدام `DATABASE_URL`
  أو بيانات إنتاجية.

## سياسات الاعتماديات

يجب استخدام `pnpm install --frozen-lockfile` في CI. عند رفض حزمة من جدار
الحزم لا يُعطّل الجدار ولا يُستخدم registry غير موثق؛ تُراجع النسخة المتاحة
وتُحدث dependency مباشرة عند الحاجة، ثم يُلتزم lockfile الناتج.

## حالات الفشل المقصودة

يمكن التحقق من أن البوابات حقيقية خارج الفرع المشارك عبر نسخة مؤقتة:

1. تعديل TypeScript مؤقتاً ثم تشغيل `pnpm typecheck`؛ يجب أن يفشل.
2. تعديل اختبار مؤقتاً ثم تشغيل `pnpm test`؛ يجب أن يفشل.
3. إضافة مخالفة lint مؤقتة ثم تشغيل `pnpm lint`؛ يجب أن يفشل.
4. تغيير `package.json` دون lockfile ثم تشغيل `pnpm install --frozen-lockfile`؛
   يجب أن يفشل.
5. وضع نمط سر معروف في ملف مؤقت ثم تشغيل فحص الأسرار المعتمد قبل الدمج؛ لا
   تُرفع القيمة أو الملف إلى المستودع.

لا تُحفظ هذه التعديلات أو أي بيانات حقيقية في commit.
