# إدارة مفاتيح التوقيع

- المفتاح الخاص لـ Ed25519 خارج المستودع وخارج حزم العميل.
- المفتاح العام فقط يمكن أن يوزع مع التطبيق للتحقق.
- يحتفظ مسؤول الأمان وبديله بنسخ الوصول وفق مخزن أسرار مؤسسي.
- لا تُطبع قيم المفاتيح أو الأسرار في CI أو السجلات أو تقارير الإصدار.
- عند الاشتباه بتسريب: إلغاء المفتاح، إصدار مفتاح جديد، تحديث المفتاح العام،
  وتوثيق نطاق التراخيص القديمة والإجراء المطلوب لها.
- يستخدم إصدار الترخيص `DAMASCUS_RELEASE_VERSION` صراحة عند بناء حزمة قديمة؛
  القيمة الافتراضية النشطة هي إصدار الجذر الحالي.

## فحص قبل الإصدار

```bash
pnpm security:scan
pnpm version:check
```
