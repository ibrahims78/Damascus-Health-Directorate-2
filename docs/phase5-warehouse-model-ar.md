# المرحلة 5 — نموذج المستودعات (تنفيذ + توثيق)

**المشروع:** مديرية صحة دمشق — الإصدار **4.2.0** (المرحلة 5 من الخطة)
**التاريخ:** 2026-09-14
**الحالة:** ✅ منفَّذة ومُختبرة (أساس النموذج)

---

## 1) الهدف
إدخال **بُعد المستودع** في نموذج البيانات: مستودعات حقيقية، ربط كل جهاز بمستودعه، وربط
الحركات والدفعات والتجهيزات بالموقع — مع **ترقيم فريد عالميًا** لا يتصادم عند دمج المواقع.

## 2) ما تغيّر

### أ) قاعدة البيانات
| الكيان | التفصيل |
|---|---|
| `warehouses` (جديد) | `code` (فريد) · `name` · `type` (central/branch) · `is_active` · `notes` |
| `document_sequences` (جديد) | عدّاد لكل (**مستودع + نوع مستند + سنة**) |
| `system_settings.warehouse_id` | مستودع هذا الجهاز |
| `transactions.warehouse_id` | موقع تنفيذ الحركة |
| `inventory_batches.warehouse_id` | موقع الدفعة |
| `equipment.warehouse_id` | موقع التجهيز |

- مُضافة إلى المخطط + `desktop-schema.sql` + **إصلاحات تراكمية** في مُهيّئ قاعدة البيانات (تعمل على قواعد موجودة دون إعادة بناء).
- **سجل المزامنة**: كيان `warehouse` جديد + إضافة `warehouseId` إلى المواد/الدفعات/التجهيزات.

### ب) الخادم
- **`ensureDefaultWarehouse()`** يُنفَّذ عند الإقلاع: ينشئ **«المستودع الرئيسي» (C)** على التثبيت الجديد،
  يربطه بإعدادات الجهاز، و**يُسنِد الصفوف القديمة** (`warehouse_id IS NULL`) إليه — إصلاح تراكمي متكرّر بدون أثر.
- **مسارات `/api/warehouses`**: قائمة/الحالي (للجميع) · إنشاء/تعديل/تعيين الحالي/رقم المستند التالي (للمدير فقط).
- **الترقيم الجديد**: `CODE-TYPE-YEAR-NNNNNN` (مثال `S01-IN-2026-000003`) عبر عدّاد ذرّي لكل مستودع،
  مع **رجوع تلقائي** لنظام الترقيم القديم إن لم يكن نموذج المستودعات مُهيّأ.
- **الحركات والدفعات** الجديدة تحمل `warehouse_id` تلقائيًا.

### ج) الواجهة
- تبويب **«المستودعات»** في شاشة الكتالوج: عرض المستودعات، إضافة مستودع (مدير)، و**تعيين مستودع هذا الجهاز**.

## 4) الهجرة والتوافق
- **إضافي بالكامل**: جداول وأعمدة جديدة، وإصلاحات `IF NOT EXISTS` — لا حذف ولا تغيير نوع.
- البيانات القديمة تُنسب تلقائيًا إلى «المستودع الرئيسي» عند أول إقلاع.
- أرقام المستندات القديمة تبقى كما هي؛ الجديدة فقط تتبع الصيغة الجديدة.

## 5) ما تبقّى من المرحلة (يُنقل إلى 5-ب / 6)
- **رصيد لكل موقع**: الأرصدة ما زالت مجمّعة على مستوى الصنف (`current_stock`)؛ الفصل إلى
  «رصيد لكل (صنف × مستودع)» يأتي مع دورة التحويل (المرحلة 6) لتجنّب ازدواج مصدر الحقيقة.
- تصفية الشاشات والتقارير بالمستودع.
