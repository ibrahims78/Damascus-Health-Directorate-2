# تقرير قبول النسخ والاستعادة — 17 أيلول 2026

## النطاق

اختبار صناعي معزول لمسار Full Backup، inspect، dry-run، merge restore،
restore point، rollback، التحقق من الكتالوج، ورفض الحزمة المعدلة وكلمة المرور
الخاطئة. لا يستخدم هذا التقرير بيانات إنتاج ولا يغلق اعتماد G3 وحده.

## الأمر والبيئة

```bash
env -u DATABASE_URL BACKUP_ACCEPTANCE_PORT=8391 pnpm backup:acceptance
```

- قاعدة البيانات: PGlite مؤقتة تُحذف بعد الاختبار.
- البيانات: صناعية.
- Node: `20.20.0`.
- pnpm: `10.26.1`.
- commit: يسجل في commit الذي يضم هذا التقرير.

## معايير القبول

| الفحص | المتوقع | النتيجة |
|---|---|---|
| إنشاء Full Backup | حزمة `.dme-sync` غير فارغة | يثبتها الأمر |
| inspect | manifest وبصمة وعدّادات | يثبتها الأمر |
| كلمة مرور خاطئة | رفض قبل التطبيق | يثبتها الأمر |
| ملف معدل | رفض MAC/checksum | يثبتها الأمر |
| merge restore | استعادة دون حذف أحدث بيانات المصدر | يثبتها الأمر |
| restore report | تقرير completed | يثبتها الأمر |
| audit | وجود `backup_package_restore` | يثبتها الأمر |
| rollback | عودة نقطة ما قبل الاستعادة | يثبتها الأمر |
| catalog verify | تحقق دون تعديل البيانات | يثبتها الأمر |

## قياس RPO/RTO

يخرج الأمر زمن التصدير والاستعادة والتراجع وملاحظة زمنية اصطناعية لـ RPO.
تسجل القيم الفعلية هنا بعد التشغيل:

| القياس | القيمة | الحد | النتيجة |
|---|---:|---:|---|
| export | 142.83 ms | للمقارنة | ناجح |
| restore/RTO | 139.53 ms | 60 دقيقة Pilot | ناجح في البيئة الصناعية |
| rollback | 137.38 ms | للمقارنة | ناجح |
| RPO observation | 0.0123 دقيقة | 24 ساعة Pilot | ملاحظة صناعية فقط |

نتيجة التشغيل: `status=passed`، حجم الحزمة 3671 بايت، و30 سجلًا و2 تغيير.
أعيد تشغيل الاختبار من نسخة العمل الحالية، ولا تحفظ كلمة مرور الحزمة أو أي
معرّف Restore Point في التقرير.

## القيود والقرار

هذا اختبار قبول قابل لإعادة التنفيذ، لكنه لا يثبت:

- الاستعادة من تخزين إنتاجي بعيد.
- أداء أجهزة Pilot أو PostgreSQL المستضاف.
- فقد مفتاح إنتاجي حقيقي.
- تمرينًا بشريًا على استمرارية الأعمال.

**القرار التقني:** قبول مسار الاختبار الصناعي.  
**قرار G3:** يحتاج قياس Pilot وتعيين مالك وبديل لمفاتيح النسخ.
