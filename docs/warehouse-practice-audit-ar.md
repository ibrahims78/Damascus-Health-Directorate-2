# تدقيق مهني شامل — ميزات Damascus Health Directorate مقابل ممارسات إدارة المستودعات العالمية

الإصدار المدقَّق: **4.4.0** · التاريخ: 2026-09-16 · النطاق: الويب + ويندوز + أندرويد (نفس الكود بعد تحقق التطابق 44/44)

## 0) الملخّص التنفيذي

| المحور | التقييم | ملاحظة |
|---|---|---|
| الممارسة التشغيلية الأساسية (استلام · إخراج · تحويل · دفعات · صلاحية · جرد أرصدة) | **جيد جدًا (8.5/10)** | دورة عمل كاملة مع FEFO وسبب إلزامي وتدقيق |
| سلامة البيانات | **ممتاز (9.5/10)** | سجل الدفعات مصدر الحقيقة + تقرير ترصيد + منع الكتابة الجزئية |
| الحاكمية والتدقيق | **جيد جدًا (8/10)** | سجل تدقيق شامل، حوكمة استيراد مع تراجع، أدوار ثلاثية |
| الطباعة والمستندات | **جيد (7/10)** | مستند حركة/تحويل/كشوف جماعية، باركود Code 39، توقيعات — ينقص QR وملصقات |
| الاستيراد/التصدير | **جيد جدًا (8.5/10)** | معاينة بلا كتابة، رفض التنفيذ الجزئي، تقرير أخطاء، نسخ احتياطي بتحقق واستعادة |
| التقارير | **جيد (7.5/10)** | 12 تقريرًا + موحّد وحسب المستودع — ينقص مؤشرات القيمة والدوران |
| متعدد المواقع والمزامنة | **ممتاز (9/10)** | حزم موقّعة ومشفّرة، جلسات مصافحة، حل تعارضات، ترقيم لكل موقع |
| المخزون الاحترافي المتقدم | **ناقص (4/10)** | لا جرد دوري (cycle count)، لا تقييم تكلفة، لا نقطة إعادة طلب، لا مواقع رفوف |
| الأمن والحماية | **جيد جدًا (8/10)** | سياسات كلمات مرور، CSRF، تحديد معدل، تراخيص موقّعة — ينقص 2FA |

**الحكم المهني:** التطبيق **يغطّي الدورة التشغيلية الأساسية للمستودع بمستوى احترافي** (استلام، تخزين بالدفعات، صرف FEFO، تحويلات بين مواقع، ترصيد، تقارير، تدقيق) وهو أقوى من كثير من الأنظمة الصغيرة. الفجوات تركّز في **طبقة الإدارة المتقدمة** (الجرد الدوري، التقييم المالي، إدارة المواقع، إعادة الطلب، الباركود الماسح) وهي إضافات مرحلة ثانية، لا ثغرات في الأساس.

## 1) المنهجية

- **جرد فعلي للكود**: 120 مسار API في 24 مجموعة، 29 شاشة، 5 حزم (ويب/ويندوز محمول+محمي/أندرويد أوفلاين+محمي).
- **مطابقة مع الممارسة العالمية**: FEFO/FIFO، تتبّع الدفعات والصلاحية، الترقيم الموحّد للمستندات، دورة اعتماد التحويل، فصل المهام، الجرد الدوري، إدارة المواقع، نقاط إعادة الطلب، مؤشرات الأداء، GS1 للباركود، المطابقة الثلاثية للشراء.
- **الأدلة**: اختبارات آلية (تطابق 44/44 · مراحل 126/126 · vitest 52/52)، وتشغيل فعلي لحزمة ويندوز.

## 2) تقييم الميزات وحدة-بوحدة

### 2.1 الحاكمية والمستخدمون والصلاحيات
- **المُنفَّذ**: أدوار (مدير · أمين مستودع · مشاهد)، سجل تدقيق لكل عملية، سياسات كلمة مرور واسم مستخدم، حدّ لمحاولات الدخول، حماية CSRF، سجل نشاط المستخدم.
- **مقابل المعيار**: فصل المهام (SoD) مطلوب في الأنظمة الرقابية. التطبيق يفصل بين القراءة والكتابة والاعتماد الأولي ✅.
- **الفجوة**: لا ربط للمستخدم بمستودع محدّد (كل مستخدم يرى كل المستودعات)، ولا اعتماد مزدوج للعمليات الحسّاسة، ولا مصادقة ثنائية.
- **التوصية**: (P0) نطاق صلاحيات لكل مستودع · (P1) اعتماد مزدوج للتسويات الكبيرة والإتلاف · (P2) 2FA للمدير + سجل جلسات.

### 2.2 الكتالوج (المواد · التجهيزات · التصنيفات · الوحدات · المستودعات)
- **المُنفَّذ**: مواد وتجهيزات، تصنيفات، **كتالوج وحدات قياس معياري** مع تطبيع الوحدات وقياس الاستخدام ومنع أرشفة وحدة مستخدمة، مستودعات بترميز فريد ومستودع مركزي افتراضي، أرشفة بدل الحذف.
- **مقابل المعيار**: الوحدات المعيارية ومنع الحذف المباشر ممارسة صحيحة تمامًا (سلامة التاريخ).
- **الفجوة**: `location` نص حر بلا هيكل (لا مناطق/أرفف/مواقع)، ولا سجل موردين، ولا بيانات مواصفات/بدائل/صور.
- **التوصية**: (P1) شجرة مواقع Zone→Rack→Bin مع ملصقات · (P2) سجل موردين ومواصفات.

### 2.3 الاستيراد من Excel
- **المُنفَّذ**: 3 مسارات استيراد (الرصيد الافتتاحي/المواد+التجهيزات · **قالب الكتالوج** · الاستيراد المجمّع)، **معاينة لا تكتب شيئًا**، **رفض التنفيذ الجزئي** عند وجود أخطاء، تقرير أخطاء CSV، حوكمة (دفعة استيراد + **تراجع**)، والتحقق من الوحدات/التصنيفات من الكتالوج الفعلي.
- **مقابل المعيار**: «Preview → Validate → Commit Atomic → Reversible» هو النمط الموصى به عالميًا لاستيراد البيانات ✅ ممتاز.
- **الفجوة**: لا دعم CSV/ODS، ولا معالج تعيين أعمدة، ولا استيراد موردين/تكاليف.
- **التوصية**: (P2) دعم CSV + معالج تعيين أعمدة.

### 2.4 التصدير والنسخ الاحتياطي
- **المُنفَّذ**: تصدير المواد بقالب موحّد (نسخة 4.0) مع الدفعات، تصدير التقارير Excel/CSV، تصدير سجل التدقيق، **نسخ احتياطي كامل** (تصدير · فحص · استعادة · تحقق · سياسة استبقاء · محاكاة قبل الاستعادة).
- **مقابل المعيار**: النسخ الاحتياطي بسياسة استبقاء + تحقق فعلية ممارسة متقدمة ✅.
- **الفجوة**: لا تصدير مجدول آلي، ولا PDF رسمي موقّع، ولا تصدير بيانات مالية.
- **التوصية**: (P2) تصدير مجدول + PDF موقّع.

### 2.5 الطباعة والمستندات الورقية
- **المُنفَّذ**: **مستند حركة A4** (ترويسة + باركود Code 39 + **خانات توقيع 3** + خاتمة إثباتية)، **مستند تحويل**، **كشوف طباعة جماعية** (الأرصدة · تحت الحد الأدنى · الصلاحيات)، وطباعة تفاصيل (مادة/تجهيز/عهدة).
- **مقابل المعيار**: مستند يتضمّن الباركود والتوقيعات والإثبات النصي يطابق مستندات المستودع الرسمية (Delivery Note / Issue Note / Transfer Note) ✅.
- **الفجوة**: Code 39 فقط (لا QR/DataMatrix أوسع استخدامًا، ولا GS1-128)، لا ملصقات للرفوف/الدفعات، لا كشف جرد أعمى قابل للطباعة.
- **التوصية**: (P1) QR/DataMatrix + ملصقات دفعات ومواقع · (P0 مع الجرد) كشف جرد أعمى.

### 2.6 حركات المخزون (إدخال · إخراج · تسوية · عهدة · تلف · مرتجع مركزي)
- **المُنفَّذ**: إدخال بمصدر توريد ومستند تسليم (داخلي/خارجي)، إخراج بسبب إلزامي، **تخصيص FEFO** مع رفض الرصيد غير الكافي (`INSUFFICIENT_STOCK`)، تسوية برصيد جديد وسبب، دورة عهدة كاملة (تسليم/إرجاع/جزئي/حالات)، تلف، مرتجع للمركزي، **دفتر دفعات يُحدَّث مع كل حركة** (على الخادم وعلى الهاتف).
- **مقابل المعيار**: FEFO + سبب إلزامي + منع الرصيد السالب + تخصيص الدفعات = الممارسة القياسية الموصى بها للصحة/المستهلكات ✅.
- **الفجوة**: لا **سند استلام بمراحل فحص** (GRN/QC)، لا استلام جزئي أو زيادة عن المُطلب، لا ربط بطلب شراء، لا **قيد عكسي** بعد الترحيل.
- **التوصية**: (P0) GRN + استلام جزئي + قيد عكسي بدل التعديل المباشر.

### 2.7 المستودعات والتحويلات (متعدد المواقع)
- **المُنفَّذ**: مستودع مركزي افتراضي، **ترقيم مستندات لكل موقع** `CODE-TYPE-YEAR-NNNNNN`، دورة تحويل كاملة: **طلب → إرسال (خصم من المصدر) → استلام (إضافة للمقصد، مع استلام مبدئي) → رفض/إلغاء**، أرصدة مستقلة لكل مستودع، **تحقق مسبق من رصيد المصدر**، وتقرير أرصدة حسب المستودع.
- **مقابل المعيار**: نمط «Transfer Order → Ship → Receive» هو نفسه المستخدم في أنظمة WMS ✅ قوي.
- **الفجوة**: لا تسجيل فروق كميات الشحن مقابل الاستلام، ولا مستند استلام موقّع بين الموقعين بشكل مستقل، ولا حالة «في الطريق» صريحة بمستند شحن.
- **التوصية**: (P1) مطابقة كميات الشحن/الاستلام وتسجيل الفروق + إشعار استلام.

### 2.8 المخزون والترصيد
- **المُنفَّذ**: **سجل الدفعات = مصدر الحقيقة**، والرصيد السريع يُرصد انحرافه عبر **تقرير ترصيد** يعرض الفروق مرتّبة، مستودع مركزي/فروع، تقرير أرصدة موحّد للمدير.
- **مقابل المعيار**: فصل «الدفتر» عن «الرصيد المخزَّن» + تقرير مطابقة من أفضل الممارسات (Perpetual inventory + reconciliation) ✅ ممتاز.
- **الفجوة**: لا **جرد دوري (cycle count)** ولا جلسات جرد/فروق/اعتماد، لا **تقييم تكلفة** (FIFO/متوسط مرجّح)، لا تحليل **ABC**، لا مؤشرات دوران/تغطية.
- **التوصية**: (P0) وحدة الجرد الدوري · (P1) تقييم التكلفة (اختياري) + تحليل ABC + مؤشرات.

### 2.9 التقارير
- **المُنفَّذ (12)**: الأرصدة · الحركات · موقف المخزون · العهد · الصلاحيات · قريبة الانتهاء · **الراكدة** · تحت الحد الأدنى · التجهيزات · **الترصيد** · الأرصدة حسب المستودع · **الموحّد** + لوحة معلومات ومخططات.
- **مقابل المعيار**: يغطي تقارير التنبيه والتشغيل المطلوبة. تقرير «الراكدة» موجود ✅ (وهو من أكثر ما يُغفل).
- **الفجوة**: لا معدل دوران/أيام تغطية/مخزون راكد **بقيمة**، لا تقارير موردين، لا تقرير إتلاف/هدر، لا مقارنات زمنية (MoM/YoY).
- **التوصية**: (P1) KPIs: دوران · تغطية · قيمة الراكد · دقة الجرد (Accuracy) · نسبة النفاد (Stockout).

### 2.10 التنبيهات
- **المُنفَّذ**: تحت الحد الأدنى، الصلاحية (منتهي/قريب)، **راكد**، تجهيزات تحت الحد، شدّات (حرج/تحذير/معلومة)، تحديث تلقائي، قراءة/حل/قراءة الكل.
- **مقابل المعيار**: قواعد التنبيه الأساسية مطابقة للممارسة ✅.
- **الفجوة**: لا إشعارات خارج التطبيق (بريد/رسائل/Webhook)، ولا قواعد مخصّصة لكل مستودع، ولا تصعيد.
- **التوصية**: (P1) قنوات إشعار + قواعد لكل مستودع.

### 2.11 المزامنة متعددة المواقع
- **المُنفَّذ**: هوية عقدة، مصافحة، عقد موثوقة، جلسات ونقل حزم، relay، كشف تعارضات وحلّها، مؤشرات مزامنة، **توقيع Ed25519 + تشفير AES-256-GCM + اشتقاق scrypt** لنقل يدوي آمن.
- **مقابل المعيار**: نقل حزم موقّعة ومشفّرة بين مواقع بلا خادم مركزي ممارسة صلبة أمنيًا ✅.
- **الفجوة**: النقل يدوي (لا قناة شبكية تلقائية)، ولا قواعد حل تعارض تلقائية.
- **التوصية**: (P2) قناة نقل اختيارية (API/SFTP) + قواعد حل تعارض.

### 2.12 تطبيق الجوّال (أندرويد) والوضع الأوفلاين
- **المُنفَّذ**: تطابق كامل مع الويب/ويندوز (**44/44**)، قاعدة بيانات محلية، دفتر دفعات على الجهاز، ترقيم مستندات، حوكمة الاستيراد مع تراجع، تفعيل محلي موقّع.
- **الفجوة**: لا قارئ باركود/QR بالكاميرا، ولا إدخال صوتي/سريع.
- **التوصية**: (P1) ماسح بالكاميرا لإدخال/إخراج سريع وربطه بالباركود المطبوع.

### 2.13 الأمن والتراخيص
- **المُنفَّذ**: تشفير كلمات المرور (scrypt)، سياسات، CSRF، حدّ معدل الطلبات، أسرار الجلسات، فصل المفتاح الخاص عن المستودع، **ترخيص موقّع لكل منصة ومربوط بالجهاز وبالإصدار**، ورفض التعديل والإصدارات الأقدم.
- **مقابل المعيار**: الترخيص المربوط بالجهاز + ربط الإصدار ممارسة تجارية/أمنية سليمة ✅.
- **الفجوة**: لا مصادقة ثنائية، ولا سجل جلسات/أجهزة، ولا تشفير قاعدة البيانات المحلية (المحمولة).
- **التوصية**: (P2) 2FA + سجل جلسات · (P1) تشفير بيانات الجهاز للنسخة المحمولة.

## 4) التوصيات مرتّبة بالأولوية

### P0 — فجوات جوهرية في الممارسة الاحترافية (يُنصح بها في أقرب مرحلة)
1. **الجرد الدوري (Cycle Counting)**: جلسات جرد (أعمى)، إدخال كميات، فروق، **اعتماد وتسوية بمستند جرد** بدل التسوية اليدوية. يرفع دقة المخزون ويُطلب في أي تدقيق.
2. **سند استلام بمراحل فحص (GRN)** + **استلام جزئي** + تسجيل المرفوض/التالف عند الاستلام.
3. **القيد العكسي (Reversal)** لكل حركة مُرحَّلة بدل التعديل المباشر، مع سبب موثّق.
4. **نطاق الصلاحيات بحسب المستودع** (مستخدم فرع يرى/يعمل على فرعه فقط).
5. **فروق كميات التحويل** (مشحون مقابل مستلم) بمستند ومحضر.

### P1 — إدارة متقدمة ورفع الكفاءة
6. **إدارة المواقع (Zone→Rack→Bin)** وملصقات المواقع والدفعات، مع تعبئة موقع إلزامي في الحركات.
7. **قارئ باركود/QR بالكاميرا** في تطبيق الجوّال + **QR/DataMatrix** في الطباعة.
8. **مؤشرات الأداء**: معدل الدوران، أيام التغطية، قيمة المخزون الراكد، دقة الجرد، نسبة النفاد، وتحليل **ABC**.
9. **نقطة إعادة الطلب/الحد الأقصى/مخزون الأمان** وحساب الكمية المقترحة للطلب.
10. **إشعارات خارج التطبيق** (بريد/Webhook) مع قواعد لكل مستودع.
11. **تشفير بيانات الجهاز** في النسخة المحمولة.

### P2 — توسّع وامتثال
12. **تقييم المخزون** (FIFO أو متوسط مرجّح) وتقارير قيمة.
13. **الموردون وأوامر الشراء والمطابقة الثلاثية**.
14. **دعم CSV/ODS ومعالج تعيين أعمدة** في الاستيراد، وتصدير مجدول + PDF موقّع.
15. **مزامنة تلقائية عبر قناة آمنة** + قواعد حل تعارض تلقائية.
16. **2FA للمدير وسجل الجلسات/الأجهزة**.

## 6) خلاصة
آلية العمل الحالية **احترافية وتطابق الأساسيات العالمية** في إدارة المستودعات (دفعات، FEFO، صلاحية، مستندات مرقّمة، تحويلات بين مواقع، ترصيد، تدقيق، نسخ احتياطي، عمل أوفلاين آمن). أبرز ما ينقص هو **طبقة الرقابة الدورية (الجرد)** و**الإدارة المتقدمة (المواقع، التكلفة، إعادة الطلب، الباركود الماسح، المؤشرات)** وهي إضافات واضحة الحدود وقابلة للتنفيذ على مراحل كما في الخارطة أعلاه.
